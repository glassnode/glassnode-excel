## Reporting a vulnerability

Don't open a public issue. Report it privately:

- **GitHub:** Security tab → "Report a vulnerability".
- **Email:** security@glassnode.com.

Include the affected version (the task pane shows it), steps to reproduce and the impact.
Glassnode has no bug bounty program.

## Supported versions

Only the latest release, the one the CDN serves, receives security fixes.
